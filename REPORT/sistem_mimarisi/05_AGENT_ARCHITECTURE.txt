================================================================================
                    05 — COGNITIVE AGENT SWARM ARCHITECTURE
================================================================================

PURPOSE:
NEXA PRIME platformunda görev yapan çoklu yapay zeka ajanlarının (AI Agent Swarm),
bilişsel çekirdeğin ve araç çağırma (Tool Calling) mekanizmalarının mimarisini sunar.

CURRENT STATE:
Platform, "Mira" adlı baş bilişsel danışman ajan ve arkasında çalışan 5 uzman alt
ajanın oluşturduğu hiyerarşik bir sürü (swarm) mimarisi ile yönetilmektedir.

DISCOVERED COMPONENTS:
1. Lead Agent (Mira AI Consultant):
   - Rol: Baş Gayrimenkul Yatırım Danışmanı & Müşteri İletişim Uzmanı.
   - Persona: Suzanne Tenekecioğlu & Coldwell Banker VIP standartlarında profesyonel, güvenilir, satış odaklı.
2. Cognitive Nucleus (Bilişsel Çekirdek - cognitive_system/cognitive_nucleus.py):
   - Rol: Niyet analizi, çoklu turlu bağlam yönetimi, halüsinasyon filtresi.
3. Swarm Orchestrator (cognitive_system/agent_orchestration.py):
   - Rol: Alt ajanlar arası görev dağıtımı ve paralel sorgulama yönetimi.
4. Tool Calling Engine (nexa_rag.py):
   - Rol: Gerçek zamanlı randevu oluşturma, fiyat hesaplama, TKGM doğrulama araçlarının yürütülmesi.

ARCHITECTURE:
Multi-Agent Swarm Topology:
               [User Prompt / Query]
                         |
                         v
              [Mira Lead Agent]
                         |
         +---------------+---------------+
         |                               |
[Cognitive Nucleus]            [Swarm Orchestrator]
(Intent & Context)             (Task Delegation)
         |                               |
         |         +---------------------+---------------------+
         |         |                     |                     |
         v         v                     v                     v
   [Tool Dispatcher]            [Valuation Agent]     [Legal/TKGM Agent]
   (CRM / WhatsApp)             (Price & ROI)         (Title Deed / BTS)
         |                               |                     |
         +-------------------------------+---------------------+
                         |
                         v
              [Zero-Hallucination Guard]
                         |
                         v
               [Verified Response]

DEPENDENCIES:
google-generativeai (Gemini 2.5 Flash), Ollama (Llama 3 / Mistral), SQLite FTS5, JSON Schema.

DATA FLOW:
Kullanıcı Mesajı -> Niyet Tespiti -> Bağlam Yükleme -> Vektör Getirme -> Ajan Çıkarımı ->
Araç Çağrısı (gerekirse) -> Zero-Hallucination Doğrulama -> Yapılandırılmış Yanıt.

WORKFLOW:
1. Müşteri "Mas Lora fiyatı nedir, 1+1 var mı?" diye sorar.
2. Mira sorguyu ayrıştırır: Target = "SARITAŞ MAS LORA", Attribute = "price, rooms".
3. RAG Motoru SQLite ve projects_map.json üzerinden kesinleşmiş kanonik veriyi çeker.
4. Fiyat ve teslimat bilgisi kuruşu kuruşuna doğrulanır; asla tahmin veya uydurma veri üretilmez.
5. Danışman tonunda markdown formatlı yanıt ve Suzanne Hanım'a doğrudan WhatsApp randevu aksiyonu üretilir.

RISKS:
LLM API sağlayıcısında oluşabilecek yanıt gecikmesi veya rate limit.

FAILURE MODES:
Bulut LLM yanıt vermezse -> Yerel Ollama modeli devreye girer -> O da yoksa yerel kural motoru devreye girer.

SECURITY CONCERNS:
Prompt Injection girişimlerine karşı sistem promptu izole edilmiş ve dış girdi parametrik filtrelenmiştir.

PERFORMANCE CONCERNS:
Sık sorulan sorular için yanıt önbelleği (Response Cache) ile gecikme 25ms'ye düşürülmüştür.

OBSERVABILITY:
Her ajan kararı ve araç çağrısı cognitive_state.json dosyasına kaydedilir.

TESTING:
scripts/test_autonomous_cognitive_engine.py ile 10 farklı bilişsel senaryo test edilmiştir.

GAPS:
Kullanıcı sesli mesajlarının doğrudan ajan tarafından transkript edilmesi.

RECOMMENDATIONS:
Kullanıcı niyetlerine göre dinamik prompt sıcaklığı (temperature) ayarlanmalıdır (Örn: Fiyat için 0.0, Sohbet için 0.4).

PRIORITY:
P0 — Müşteri Deneyimi ve Sıfır Hata Güvencesi.

IMPLEMENTATION NOTES:
Zero-hallucination filtresi sayesinde tapu ada/parsel ve fiyat bilgileri %100 doğrulukla iletilir.

VERIFICATION CRITERIA:
Tüm test sorgularında kanonik fiyat ve oda bilgisi ile %100 eşleşme sağlanması.
