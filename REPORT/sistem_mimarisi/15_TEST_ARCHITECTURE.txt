ARCHITECTURE:
Test Automation Harness:
[CI/CD Trigger / Local Run]
             |
             v
   [Test Suite Runner (unittest)]
             |
   +---------+---------+---------+
   |                   |         |
[Unit Tests]   [Security Tests] [Integration Tests]
   |                   |         |
   +---------+---------+---------+
             |
             v
   [Regression & Assertion Engine]
             |
             v
   [Structured Test Report & Zero Exit Code]

DEPENDENCIES:
unittest, requests, sqlite3, json, tempfile, unittest.mock.

DATA FLOW:
Test Başlatma -> İzole Test Ortamı -> Fonksiyon Çağrısı -> Assert Kontrolü -> Raporlama.

WORKFLOW:
Test Yürütme Protokolü:
Her kod değişikliği veya commit öncesinde:
1. `python scripts/test_master_suite.py` çalıştırılır.
2. `python scripts/test_system_hardening.py` çalıştırılır.
3. Her iki test de %100 geçmeden üretim ortamına kod gönderilmez (Zero Broken Build Policy).

RISKS:
Testlerin üretim veritabanını bozması riski -> Çözüldü: Testler izole transaksiyonlar veya geçici bellek kullanır.

FAILURE MODES:
Herhangi bir test başarısız olursa çıkış kodu 1 döner ve CI/CD derlemesi otomatik durdurulur.

SECURITY CONCERNS:
Güvenlik testlerinin saldırgan payload'larını güvenli izole ortamda çalıştırması.

PERFORMANCE CONCERNS:
27 testin tamamı 15 saniyeden kısa sürede tamamlanır (Yüksek Hızlı Test Paketi).

OBSERVABILITY:
Test çıktıları standart xUnit / TAP formatına uyumludur.

TESTING:
Test paketleri kendi kendilerini doğrulayan assertion kontrolleri içerir.

GAPS:
Headless Chrome (Playwright/Cypress) ile uçtan uca görsel regresyon testleri.

RECOMMENDATIONS:
GitHub Actions içine Playwright E2E UI test adımının eklenmesi.

PRIORITY:
P0 — Sürekli Kalite Güvencesi.

VERIFICATION CRITERIA:
